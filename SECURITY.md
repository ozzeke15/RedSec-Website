# Vulnerability disclosure

Report suspected vulnerabilities privately to info@redsec.be, the existing
contact published on the website. Include the affected URL, impact and minimal
reproduction steps. Do not include credentials or personal data in public issues.
This contact is reused from the site; mailbox monitoring and response times have
not been independently verified. The owner should confirm responsibility before
merging and renew `.well-known/security.txt` before 2027-10-01.

No bug bounty, reward or testing authorization is implied. Avoid disruptive
techniques, accessing other people's data or changing systems.
